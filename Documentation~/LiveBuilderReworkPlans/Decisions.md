# Решения менеджера по ходу доработки

Временный файл на время доработки: решения, которые меняют планы этапов. Читать вместе с планами.

- **Этаж — «Storey» везде:** в интерфейсе и в иерархии здания — `Storey 1`, `Storey 2` … (не `Floor N`, как в Stage2and4.md):
  «Floor» в интерфейсе уже значит «пол». Перекрытие — `Slab`, крыша — `Roof`.
- **Интерфейс этапа 3 — по разбору дизайнера** `UX-Review.md` и макету `UX-Mockup.html`; где они расходятся с
  `Stage3and5and6.md`, главнее разбор дизайнера, если архитектор не нашёл, почему так нельзя в Unity.
