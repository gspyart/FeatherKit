## После 2.2
- Вырез-коробка = `GeometryCutter` формы Box без скруглений, оси вдоль осей объекта (повороты на 90° можно), объект версии 2. Всё про неё — `GeometryCutterSolverBoxes`: чей кусок (`CollectingModelOf` — ближайший `BoxModel`, через стену по линии не идёт), коробки солвера (`BoxesOf`, с копиями вверх), стороны в осях объекта.
- Сборщик кладёт её в солвер куском (`BoxModelSolverBox.ForCutter`, источник — `LiveBuilderCutRules.SourceOf(cutter, pieceKey)`). Коробки своего объекта режет всегда, «Cuts» — только про стены и перекрытия (как у вырезающей коробки). Свои дочерние объекты в солвере не режет.
- Способ — `LiveBuilderCutRules.MethodOf` / `PreciseMethodOf`; `GeometryCutterLookup.CuttersFor` отдаёт в вычитание только `MeshSubtraction`. Стены — проём по линии, только если коробка проходит толщину везде, где задевает (`SplineWallRebuilder.IsThroughThickness`), иначе ниша вычитанием. Решение одно на вырез и стену (у стены по линии — и на её пол с потолком).
- **Отступление:** проём по линии и дыра в плане своих материалов стенок не умеют. Вырез с материалом (общим или стороны) режет стены и перекрытия вычитанием, свой объект — клетками с материалами. Если нужен точный проём с материалом — добавлять материал в `SplineWallHole` / `SplineBuildingSlabHole`.
- **Отступление:** точно режут только вырезы-куски объекта. Проём — ребёнок стены по линии (двери в перегородках) — по-прежнему вычитание; для 2.6 (8.3 «проём по осям режет стену точным проёмом») это надо добавить отдельно в `CollectHoles`.
- Старое правило (версия 0) не тронуто: там вырезы всегда вычитаются, старые вырезающие `BoxModelPart` режут как раньше. Вычитание из перекрытий без материала берёт торцы здания (`OuterWallSubmesh`) только в объекте версии 2.
- Объект, где одни вырез-коробки (группа с проёмом), меша не строит — как пустая группа (`BoxModelRebuilder.HasNothingToBuild`).
- Привязка к этажам на вырезе даёт копии через его `CopiesUp` — сборщик второй раз их не повторяет. Вырез внутри привязанной группы или повтора в солвере повторяется (в вычитании — нет): развести в 2.4 через `LiveBuilderArrayCopyPoses`. Сверка привязки не подгоняет высоту выреза под этаж, как подгоняла вырезающей коробке «во весь этаж».
- Инструменты: коробка «Cut», вдавленный кусок грани, прямоугольный «Проём» в объекте — `BoxModelFactory.CreateCutterBox` (опора в углу, `ShapeOffset = (w/2, 0, d/2)` — как в 8.2). «Make Cut» / «Make Box» — `GeometryCutterBoxConversion`, один шаг Undo. Вдавленный кусок грани после отпускания углубляют ручки выреза, а не дальняя грань.
- Вырез-коробку правят «Коробка» (ручки граней `BoxModelPartHandles.DrawHandles(model, cutter)`, если опора в углу и оси объекта) и «Проём». Выделение граней («Грани») и выдавливание с Ctrl у неё нет. Покраска граней дыры — в стороны выреза (`LiveBuilderMaterialSlots`).
- Подписи переведены в правленых классах: карточка коробки, «Коробка» и «Проём» (имена Box и Cut), подсказки жестов, места материала, строка о выделенном. Подсказки у других классов (`FaceSelectionHint`, выдавливание) ещё русские — склеиваются с английскими.
- `BoxModelShapeCollector` — 319 строк кода: вынести лестницу (`BoxModelStairsLayout`) в 2.3.

## После 2.6
- Миграция — папка `Editor/.../LiveBuilder/Upgrade/`. Когда: `LiveBuilderUpgrade` (открытие сцены и префаба из `Assets/`, ассеты пакетов не трогает; сначала префабы-ассеты старых экземпляров сцены — вложенные и базовые раньше; `SuppressAutomatic`, событие `Upgraded`), меню `Tools/FeatherKit/Live Builder/Upgrade Project Data…` — `LiveBuilderUpgradeProjectCommand`. Порядок одного прохода — `LiveBuilderUpgradeRun`: Array достроить → старая пересборка всего → снимок → здания → Array → привязки → «Interior» → группы повтора → копии вверх → комнаты → вырезающие коробки → версии → разворот повторов, чьи копии режут друг друга → F1–F4 → «Где режет» → материал выреза и тонкие коробки → новая пересборка всего → сверка → итог. Без Undo (кроме `ArrayModifierBuilder.Remove/Apply` — у них Undo внутри).
- Идемпотентно: признаки старых данных — `LiveBuilderUpgrade.NeedsUpgrade` (версии 0 у `BoxModel` / `SplineBuilding`, привязка, `BoxModelRepeat`, Array на объекте Live Builder, копии вверх, вырезающая `BoxModelPart`, `LegacyOwnGroup`, в сцене — «Own object» без постройки над вырезом). Содержимое экземпляров префабов решает их ассет; правка экземпляра — только «Где режет».
- «Own object» без постройки над вырезом теперь не режет ничего (`LiveBuilderCutRules.Reaches`); в сцене миграция делает такие вырезы «Everything it touches», в префабе-ассете не трогает (место решает расстановка — в c1 так получили переопределения у 24 экземпляров лоджии).
- Сверка «как было» — `LiveBuilderUpgradeSnapshot`: тело каждого объекта старых данных клетками солвера (`LiveBuilderUpgradeBody`: «как стало» = объект + его «Kept From Cuts» + копии развёрнутого повтора, из вложенного вынуты вырезы-коробки, что режут его вычитанием) и грани мешей стен, частей зданий и объектов без вложенных (`LiveBuilderUpgradeMeshFaces`: площадь и габарит по «материал, направление»). Объём меша не годится — меши частей зданий не замкнуты.
- F1 (`LiveBuilderCutOrderUpgrade`): коробка после пересекающего выреза — во вложенный «Kept From Cuts» целиком, у того же родителя; оси вложенного — оси внешнего объекта (тело сверяется клетка в клетку), материал, фаска, развёртка (`TextureAlignment`) — от внешнего. Грань вровень с коробкой другого материала — строка «may flicker». Комната и лестница переехать не могут — во вложенный встаёт их часть внутри выреза простой коробкой (`LiveBuilderKeptRegion`). F2 — стена в пустоте комнаты / во всю высоту коробки. F3/F4 — `LiveBuilderCutReachUpgrade`: «Everything it touches», если по габаритам не прибавится целей, иначе копия выреза во вложенном.
