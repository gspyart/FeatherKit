# Заметки на уровне

> Руководство модуля FeatherKit `LevelNotes`. Список модулей — в [README](../README.md#что-внутри).

## Что это и зачем

Заметки, приколотые прямо к месту на уровне: «тут поставить лампу», «почему игрок не допрыгивает?», «проверь этот угол».
Мысль остаётся там, где она родилась, а не в отдельном файле, где потом надо объяснять, о каком углу речь. Оставлять и читать
их может и человек, и агент, который работает в редакторе через Unity MCP. В игру заметки не попадают.

## Пример

Похоже на стикеры на чертеже: прилепил жёлтый листок к окну на плане — и каждый, кто откроет план, увидит его на этом самом окне.

Как это выглядит в редакторе:

1. Дизайнер бегает по уровню в игре и замечает, что прыжок между крышами слишком длинный. Выходит в редактор, наводит мышь
   на край крыши в окне сцены и жмёт N.
2. На крыше встаёт флажок, а у курсора открывается поле. Он выбирает тип «Вопрос», пишет «Длинный прыжок — сократить на метр?»
   и жмёт Enter. Над флажком видна первая строка — «Длинный прыжок — сократить на метр?».
3. Агенту дают задачу «разбери заметки на уровне». Он находит все компоненты заметок на сцене, читает текст, сдвигает крышу
   и ставит заметке галку «сделано», а рядом оставляет свою: «Сократил на 1 м, проверь прыжок» с типом «Для агента» и своим именем.
4. Утром дизайнер открывает окно со списком заметок, видит новую, кликает по ней — камера сцены летит к флажку.

## Как пользоваться

**Поставить.** Мышь над местом в окне сцены → **N**. Флажок встаёт на поверхность под курсором — и на меш без коллайдера.
Открыто несколько сцен — заметка ложится в сцену того объекта, на который навели; под курсором пусто — в активную.
У курсора — поле: сверху тип, ниже текст.
- Enter — создать, Shift+Enter — новая строка, Tab — следующий тип, Esc — отменить
- клик мимо поля — создать, если текст набран; пустой текст — заметка не создаётся
- тип запоминается до следующей заметки

**Увидеть.** Флажок цвета типа, над ним первая строка текста. У выделенной — весь текст и кто оставил.
Сделанная — бледная, с галкой перед названием. Вдали текст прячется, флажок остаётся заметным.
Флажков не видно — включены ли гизмо в окне сцены (кнопка Gizmos).

| Тип | Цвет | Для чего |
|---|---|---|
| Идея | жёлтый | что можно сделать |
| Задача | оранжевый | что надо сделать |
| Вопрос | голубой | что непонятно, нужно решение |
| Для агента | зелёный | поручение агенту или его ответ |

**Править.** Клик по флажку выделяет заметку. В инспекторе: текст (первая строка — название над флажком), тип, «Is Done», кто оставил.
Двигать — как любой объект.

**Удалить.** Delete. Всё — создание, правка, удаление — отменяется Ctrl+Z.

**Список всех заметок** — `FeatherKit → Level Notes`. Заметки всех открытых сцен: цвет типа, первая строка, галка «сделано», кто оставил.
Клик по строке — выделить заметку и навести на неё камеру сцены. Сверху — какие типы показывать и «Скрыть сделанные».

**Куда кладутся новые** — Project Settings → FeatherKit → Level Notes, поле «New Notes Group»: путь от корня сцены, например
`Level/Debug/Notes`. Каких групп пути нет — создаются. Пусто — в корень сцены.

**Клавиша** — Edit → Shortcuts → FeatherKit → Add Level Note. Срабатывает, когда мышь над окном сцены, даже если в фокусе другое окно.

## Для агентов

Найти — все компоненты `LevelNote` на сцене (поиск по компоненту через Unity MCP). Поля:

| Поле | Что |
|---|---|
| `text` | текст; первая строка — название над флажком |
| `kind` | `Idea`, `Task`, `Question`, `ForAgent` — только цвет |
| `isDone` | сделано |
| `author` | кто оставил: имя человека или агента |

Оставить — одной строкой через `execute_code`, отменяется Ctrl+Z. Заметка ложится в **активную** сцену — открыто несколько, сначала сделай нужную активной:

```csharp
FeatherKit.EditorTools.LevelNotePlacer.CreateNote(
    new Vector3(12f, 0f, 30f), "Сократил прыжок на 1 м\nПроверь с разбега", FeatherKit.LevelNotes.LevelNoteKind.ForAgent, "Level designer agent");
```

Сцену после этого надо сохранить — заметка живёт в файле сцены.

## Технические подробности

- Заметка — объект `Note N` (номер — следующий за самым большим на сцене) с тегом `EditorOnly`: в сборку игры не попадает.
  Сам компонент в игре ничего не делает и ничего не рисует
- Точка под курсором: сначала меши (`HandleUtility.PlaceObject` — как перетаскивание префаба в сцену), потом коллайдеры,
  потом плоскость земли на высоте 0, иначе 10 м перед камерой
- Флажок рисуется гизмо (`DrawGizmo`) из редакторской сборки — код рисования не попадает в игру. Флажок всегда лицом к камере;
  вблизи — в метрах мира (древко 1,6 м), вдали не мельче нескольких пикселей. Текст — `FGizmos.Label`, его размер — от ползунка размера гизмо
- Кто оставил заметку клавишей — имя в Unity, без входа — имя пользователя компьютера
- В режиме префаба клавиша не ставит заметку — только на сцене
- N в Unity по умолчанию занята только у системы частиц (`ParticleSystem/Reverse`): когда выделена система частиц, N отдаётся ей

| Класс | Назначение |
|---|---|
| `LevelNote` | Компонент заметки: текст, тип, «сделано», кто оставил |
| `LevelNoteKind` | Тип заметки: идея, задача, вопрос, для агента |
| `LevelNotePlacer`, `LevelNoteDraft` | Клавиша N, точка и сцена под курсором, создание заметки; `CreateNote` для агентов. Черновик — заметка, которая ждёт текста |
| `LevelNoteTextPopup` | Поле текста и типа у курсора |
| `LevelNoteGizmoDrawer`, `LevelNoteFlagShape` | Флажок и подпись в окне сцены, призрак флажка при вводе текста |
| `LevelNoteKindStyle` | Цвет и подпись типа — одни на флажок, поле и список |
| `LevelNotesWindow` | Окно-список заметок открытых сцен |
| `LevelNotesProjectSettings`, `LevelNotesProjectSettingsPage` | Группа новых заметок — Project Settings → FeatherKit → Level Notes |
